Every command takes three global options. `--no-color` and `--color=always|never|auto` reach help and the handler's new `ctx.runtime`, which carries the caller's colour flag and `quiet` to roundel's policy and flagstaff's `hoist`. `-q`/`--quiet` silences progress and framework hints, such as a deprecation warning, and never data or errors. `--timeout <duration>` (`500ms`, `5s`, `2m`) aborts the new `ctx.signal`, runs the exit handlers once and leaves with the new `ExitCode.TIMEOUT`, 6. All three can be typed before the command too. A command that declares an option of the same name keeps it. Root and command help list them under `Global options:`.
