Measure the agent axis. `npm run bench` reports hangs, exit-code discipline, structured
output and recovery bytes for the same demo CLI built on burgee, on commander and on yargs.

The family's headline claim is that a CLI on this layer is better for an agent, and until
now that claim had **no number at all** — the two agent control bands were declared and had
zero data points. The full B1 needs a model and a weekly workflow; everything an agent's
success actually turns on can be measured without one, and this measures that.
