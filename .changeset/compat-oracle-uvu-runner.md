A suite run by `uvu` is graded by the summary uvu prints, one file per run: a file uvu cannot load is one failure, and a run that ends with no summary is an error. A suite on `uvu -r esm`, which does not start on Node 24, runs with tsx where `esm` stood. The vendor step brings a sibling helper named with no extension (`./utils`) as `utils.js`. kleur is graded this way, 15 / 15 against a control of 15 / 15.
