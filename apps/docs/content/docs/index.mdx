**burgee** is a CLI framework built on one declaration. You declare a command once, and
help, `--json`, `--schema`, an MCP server, shell completions and TypeScript types are all read
from that declaration, so none of them can drift from the others.

```text
defineCommand()  ──▶  manifest  ──┬──▶  human help
                                  ├──▶  --json      one stable envelope
                                  ├──▶  --schema    versioned, one document per surface
                                  ├──▶  --mcp       an MCP server, generated
                                  ├──▶  completions bash · zsh · fish · pwsh
                                  ├──▶  TypeScript types
                                  └──▶  docs + llms.txt
```

## Contracts an agent can act on

An agent calling a CLI through a shell pays in calls, tokens and misreads. A burgee command
gives it contracts instead of prose to interpret:

- a stable `{ ok, data }` envelope under `--json`, and a versioned schema under `--schema`;
- an exit code that says *rewrite the command* (`2`) rather than *something went wrong*;
- a `fix:` line on a mistyped command, which the agent can run as written;
- `--explain <option>`, which says whether a value came from a flag, an environment
  variable, a config file or a default;
- the same commands as MCP tools under `--mcp`.

[Your CLI is an agent tool](/docs/agent-surfaces) has each surface.

## One supply chain

Ten packages, one repository, one release pipeline, and no dependency outside the burgee
family in any of them. Six take nothing at all; the other four take only each other.
[Packages](/docs/packages) has each one.

## Proved by each incumbent's own suite

Every drop-in path is graded by the test suite of the package it replaces, vendored
unmodified apart from the import specifier and run in CI beside a control that runs the real
package. The rates are on [Compatibility](/docs/compatibility), generated, never hand-edited.
The [benchmarks](/docs/benchmarks) publish every comparison, the rows burgee loses included.

## Switch in one command

```bash
npx burgee migrate --dry-run
npx burgee migrate
```

burgee replaces commander and yargs, and the family replaces chalk, ora, string-width and the
other incumbents graded level with their own suites. `burgee migrate` rewrites the import
specifiers and nothing else, then prints the install command to run next. For one commander
program, that is one line:

```diff
- import { Command } from 'commander';
+ import { Command } from 'burgee/commander';
```

[Migrate](/docs/migrate) has the whole report, and [burgee vs commander](/docs/vs/commander)
and [burgee vs yargs](/docs/vs/yargs) go through each API.
