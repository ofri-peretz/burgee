# SC8 evidence

Every SC8 head-to-head run, kept whole: what ran, when, under what load, what each engine said
about each mutant, and why a run was thrown out.

- [`RUNS.md`](./RUNS.md): the ledger, generated by `node scripts/sc8-ledger.mjs`. Valid and void runs, the
  medians per package, and whether the loads are close enough to compare.
- `runs/<label>.*`, one set per run:
  - `.meta`: engine, package, start, end, `wall_s`, `git status` after the run.
  - `.loadlog`: the 1-, 5- and 15-minute load, sampled every minute. A gap means the machine slept.
  - `.foreign`: other processes over 20% CPU when the run started.
  - `.json.gz` (oxmutate): counts, phases, stats, and the verdict for every mutant.
  - `.result.json.gz` (Stryker): `scripts/mutation.ts`'s summary, with every undetected mutant.
  - `.report.json.gz` (Stryker, from round 2's compat-oracle runs on): Stryker's full per-mutant
    report, so a Killed can be told from a Timeout.
  - `.log.gz`: the engine's own output.
- [`void.json`](./void.json): the cause of each void run that was found by hand.
- [`harness/`](./harness): the scripts that made the runs. `h2h.sh` runs engines in turn, records
  load and restores the package afterwards. `prof.mjs` drives oxmutate. `survdiff.mjs` diffs
  survivors.
- [`survivors/`](./survivors): survivor diffs between Stryker and oxmutate runs on the same package.

## Survivors: what the diffs say (caique, round 2)

- **Against round 2's S1, 69 mutants survive only under oxmutate. That count belongs to S1.** S1 has
  680 Stryker survivors. The other two complete Stryker runs have 744 (round 1) and 745 (S2b), and
  against them only 12 or 13 survive only under oxmutate. Most of the 69, including the 48 static
  constants in `clack-core.ts`, are mutants that S1 alone detected.
- **12 mutants survive under oxmutate and are detected by both of those Stryker runs.** They are the
  same 12 each time ([`caique-r2-S2b-vs-O2.txt`](./survivors/caique-r2-S2b-vs-O2.txt)): logical
  operators and method expressions in prompt code, not static constants. Whether Stryker detects them
  as Killed or as Timeout is answered by a Stryker run that keeps its per-mutant report, so they stay
  open until then.
