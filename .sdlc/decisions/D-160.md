**A ceiling row against `bellpull`, graded over three of twelve directories, kept out of `migrate`.** *Target:* the package root `bellpull` — no façade is built and none may be named before it exists (D-006, D-007). Every execa file imports `execa`, which bellpull does not export, so each dies at link time: **0 / 1048**, control **1048 / 1048**; graded once over all 149 files the same day, the target also passed **0**. *Slice:* `arguments/`, `methods/`, `return/` — how a command is built, the entry points, the result and error a caller reads, which is bellpull's whole overlap (R1, R6). The control over all twelve directories measured **647 s** at upstream's `concurrency: 1` (5,124 / 5,125, one `terminate/` case lost to load), past `SUITE_TIMEOUT_MS`'s 300 s and over half the ratchet job's 20 minutes; the slice's control runs in ~65 s. The other nine are vendored and named in `ungradedDirs` with that reason, so nothing is silent and the zero is not the slice's alone. *Not a drop-in:* new `Host.ceiling` (with the reason) and `"ceiling": true` in `baseline/execa.json`; `migrate-drop-ins-lock` and burgee's `compat-baseline-lock` leave such a row out, `baseline-scope.test.ts` holds flag and field together, and the compatibility page gains a *Graded as a ceiling* section. The alternative, an `execa → bellpull` entry in `DROP_INS`, would have had `migrate` report bellpull as execa's path — the recipe R7 calls a defect. *Harness:* `HostImport.namedOnly` rewrites a bare specifier only where a module is named, because the graceful fixtures `import … from 'execa'` and `test/verbose/info.js` sets `NODE_DEBUG: 'execa'`; the literal rewrite failed three of `info.js`'s fifteen cases against execa itself, measured (`vendor.test.ts`, red on the unfixed `rewriteAt`). *tinyexec:* 1.3.1 pinned exactly in `benchmarks/package.json` and ignored by dependabot (`pinned-incumbent-lock`); B4 pair `bellpull` — `run` against `x`, not a drop-in pair, the one call a program makes to spawn — **5,901 / 5,969 B, 0.989**, gated at 1 (`lighter-than-tinyexec`), byte ratchet 6,000 (measured + 80 B for CI, rounded to fifty).
