**The data half is built everywhere and the feedback loop exists once.** Measured 2026-09-21. PRINCIPLES 7 asks three things of an extension surface: the plugin is data validated against a published schema, there is a **`check` command that renders it every way it can be seen**, and the bar is **measured weekly** — an agent given the schema and one example writes a passing plugin in one turn. Eight of nine packages publish `./plugin` and `./schema.json` and all eight export `validate`, so the first is done. The second exists in **one** package (`flagstaff`) and the third in **one** case (`evals/cases/flagstaff-plugin-from-schema.json`). `linegauge` has no extension surface at all. A surface nobody can check is a surface nobody outside this repository can write against, which is the difference between an extension point and a published interface. `scripts/extension-surface-lock.test.ts` holds the table so the gap can close but cannot drift, and enforces the one implication that matters today: a package that ships `check` ships an eval, because a loop without a measurement is the bar claimed rather than met. **Not** made a failing gate — the six missing commands are scheduled, and failing on scheduled work is how a check teaches people to read red as normal. `check` cannot be shared: flagstaff's is 200 lines of rendering a spinner in five output modes, and every package's renders its own contribution kinds
