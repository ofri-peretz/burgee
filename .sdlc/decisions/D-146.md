**Built, as `--format=agent`.** The owner asked for it on 2026-09-24, which is the decision D-115 was waiting on; D-115 deferred it because its justification was token cost and B1 had never run, and that is answered here the only way a size can be — by measuring the string. The format is logfmt, one line per record: a list result is one line per element, an object is `key=value` pairs with nested keys dotted, lists of scalars comma-joined and a list holding an object indexed, a value quoted (JSON string escaping) only when it is empty or holds a space, `=`, `"`, `,` or a control character, whitespace collapsed, and no envelope, `meta` or summary. `null`, `undefined` and `[]` are no records and print nothing; the exit code is still the result's own (E1) and `changed` still rides in the record (N7). Measured on six representative results (a twelve-row list, a nested show, a status, a list of names, a count, an idempotent write): **1,294 bytes against `--json`'s 1,882, 31.2% smaller**, 20.5% on the list at the low end; `agent-format.test.ts` fails if any one is not smaller or the set is not 20% smaller, and fails 19 of 26 on the unfixed engine, which refuses the flag as an unknown option. **`--json` wins when both are typed**, so O1 and D-140 are untouched — a `--json` failure is still one envelope on stdout — and a failure without `--json` stays prose on stderr, since a failure is not a record. The flag is burgee's only before `--` (G5) and only for a command that declares no `format` option of its own: the program wins. **Bytes:** the flag is read where `--json=` already was, inside the lazily imported `fields.js`, so the startup path gains one more alternative in the test that loads it and a `lines?.()` in `emit` — **+71 B**, core 30,107 -> 30,178, burgee ÷ cac 2.881 -> 2.887 under wave-5's 2.9, which does not move; the formatter is its own chunk. Two limits, stated: the commander and yargs façades do not take the flag — it is the engine's, and a façade program's argv is the incumbent's to parse — and neither help nor `--schema` lists it yet
