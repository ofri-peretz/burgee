**R8's spawn half is a B5 pair, `bellpull ÷ tinyexec`, gated at 1.0 — R8's own bar — and R8 reads `Built`.** The workload (`benchmarks/fixtures/runtime/bellpull-tinyexec.mjs`) is the call a program makes to run a tool and read its answer: `run('node', ['--version'], { runtime })` against tinyexec's `x('node', ['--version'])`, each awaited to the child's close with its stdout collected, after `check()` proves both print the running node's version. A bare name rather than a path, so bellpull's own `PATH` walk is inside the number it is gated on. `node --version` rather than `true` because the parity check runs in `npm test` on the Windows compat cells too, and it exits before V8 initialises, so the child is as cheap as a portable one gets. Both sides read a `PATH` that starts with the running node's directory, so an nvm shell cannot hand them different binaries. **Measured on an M4 Pro at load 55–60: 0.922, 0.932, 0.933, 0.940, 0.949 across five runs — median 0.933** (median of 11 interleaved per-round ratios, 20 spawns a side a round, three warm-up rounds, fresh process: B5's method, D-20260929-b5-runtime-ratchets). Proven red: with `setTimeout(2)` added to `run()` in `packages/bellpull/dist/run.js` the pair read **1.046**, `verdict` 1; restored, 0.955, `verdict` 0. **Why B5 and not a B2 cold-start row**, which the task first named: the coordinator moved it onto the B5 axis that landed the same day (#744), and R8 asks about the spawn, not about Node starting — a B2 row would be two node start-ups and an import with the spawn inside, the delta diluted by everything around it. **Why 1.0 and not the B5 derive rule** (largest of the last 10 CI medians × 1.25): R8 states its bar, and a ceiling derived from 0.933 × 1.25 would be 1.2, and call a bellpull a fifth slower than tinyexec green — the ratchet's `rule` says so, `runtime.test.ts` locks ceiling ≤ 1.0 and target 1, and the ceiling may still come down once the derived figure is under 1.0. **If CI reads above 1.0, the answer is to find why bellpull is slower on that runner and fix it, not to raise this ceiling**; raising it takes a newer decision than this one (`scripts/ratchet-steps.ts`).
