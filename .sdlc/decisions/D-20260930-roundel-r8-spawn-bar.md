**One allowance for both colour entries: each may cost no more than picocolors + 10 ms to start, read as the median of per-round differences in B2's interleaved spawns, and gated there as `cold-start-delta-ms` with `max: 10`.** B2 (`benchmarks/axes/perf.ts`) now spawns `picocolors`, `roundel/tokens` and `roundel/chalk` beside the parsers, each fixture importing its package and painting the line every fixture prints, under `NO_COLOR` because picocolors colours whenever `CI` is set and roundel follows the CI vendor table — without it the same fixture prints escapes on a runner, which `perf.test.ts` proves by running them under `CI=true GITHUB_ACTIONS=true`. `ROUNDS` goes 42 → 40 so the rotation stays a whole multiple of the variant count (ten). **Why a difference and not a ratio:** R8 writes the bar in milliseconds, and the paired difference of two spawns seconds apart cancels the machine's own startup as a ratio does — it is not the absolute ceiling #27 ruled out. **Why this reading:** R8's parenthesis gives picocolors' two costs, bytes and time, and "`./chalk` … ≤ picocolors spawn delta" is the same bar stated for the second entry. **Measured 2026-09-30, M4 Pro, 60 rounds:** bare node 26.80 ms; picocolors +2.97 ms over it; `roundel/tokens` +1.26 ms over picocolors; `roundel/chalk` +2.97 ms over picocolors. **The literal alternative, recorded because it is not met:** if "picocolors spawn delta" means picocolors' own 2.97 ms over bare node, `roundel/chalk`'s 5.68 ms over bare node fails it, and so would any four-module ESM entry that imports `node:util` — measured alone, `import 'node:util'` costs 1.16 ms and a one-file package's resolution and load about 3.4 ms, so the floor is above the bar before `roundel/chalk` does anything. **Rejected:** a ratio gate `roundel/chalk ÷ picocolors ≤ 1` (1.110 measured, red on every run, for a bar no ESM entry of this shape can meet); a parallel axis beside B5 (B5 times a workload in-process; R8 is a spawn, which is B2's). The 10 ms is about three times the larger measured row, and CI's two-core runner measures bare node about 10% slower than that machine, so a runner's bad minute does not red-light a PR that touched nothing. `ratchet.test.ts` sees the gate go red at +10.01 ms and stay green at +10.
