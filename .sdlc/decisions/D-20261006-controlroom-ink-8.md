**`controlroom/ink` follows ink 8.0.0 and grades 1304 / 1304 against it; the control, ink 8.0.0 itself, grades 1303 / 1304 in the same harness. ink 6.8.0 is graded as `ink-6` in `PREVIOUS_MAJORS` — 540 / 584, control 584 / 584 — and not claimed.** Measured on darwin, Node 24.13.0, 2026-10-06; the ratchet's ubuntu run is the published one.

**The suite.** ink 8.0.0 (tag `v8.0.0`, commit `26d2c3f8`, 2026-10-03) runs `FORCE_COLOR=true node --import=tsx --test --test-concurrency=1 'test/*.{ts,tsx}'`. Vendored, it is 95 files: 81 gated and 14 informational (they import only ink's own modules), 1,314 gated cases of which five skip themselves upstream (four Yoga known-failures and one that needs a TTY stdin), so 1,309 counted. The informational line is 332 / 332 on the control.

**What the oracle needed, and none of it is about ink.**

- The `node:test` arm takes `tsLoader` — it passes `--import <tsx>` ahead of `--test`, as upstream's script does — and a new `testConcurrency` for its `--test-concurrency=1`. `grade.test.ts` holds both for real: two `.ts` files with an `enum` (not erasable, so Node's own type stripping refuses them) that share a lock only a serial run satisfies; it was red with the arm reverted.
- `suiteTimeoutMs` gives the serial run 600 s against the oracle's 300 s default; the control with its informational files measured 268 s.
- `rewrittenDirs` copies a directory outside the test dir and rewrites its imports like a fixture tree. `render.tsx` runs fourteen of upstream's `examples/*` under a PTY and `alternate-screen-example.tsx` imports one; each imports `../../src/index.js`, which no published package has. `extraDirs` was not reused because its files must arrive byte for byte — dotenv 17's root `config.js` requires `./lib/main`, the public specifier seen from the root. `vendor.test.ts` holds it.
- `migrated: { chalk: 'roundel/chalk' }`, the boxen 9 mechanism: `helpers/force-colors.ts` sets `chalk.level = 3` on the suite's chalk 6, which ink colours through. With the suite's chalk moved to the instance the drop-in colours through, the seven background cases the 6.8 row excluded as runner-dependent colour are graded, and pass.
- `targetInternals` grows from two paths to nine: `log-update.js`, `ink.js` (`homeAndEraseDown`), `components/ErrorOverview.js`, `kitty-keyboard.js` (`resolveFlags`), `instances.js`, `sanitize-ansi.js`, `wrap-text.js` (with `wrapTextCache`), beside the two it had. Each is the drop-in's module of the same job.
- The compatibility page published `excludes` for `HOSTS` only; it now publishes the previous majors' too, as it already did their allowances, conditional cases and ungraded directories. `compat-page-subtractions.test.ts` went red on `ink-6`'s nine without it.

**Five cases are excluded, and one control failure is allowed.** `build-output.ts`'s four cases grade ink's repository — its `before` hook runs `npm run build` and asserts `build/`, the `exports` of ink's `package.json` and its `tsconfig.json` — and `style-types.ts` type-checks `src/global.d.ts`; ink 8.0.0 fails all five here, as any implementation would. What the type case checks — `minWidth` and `maxWidth` take numbers only — is held for `controlroom/ink` by `@ts-expect-error` lines in `src/ink/types.test.ts`, which the package's typecheck compiles. The allowance is `measure-element.tsx` › `calculate layout while rendering is throttled`: ink 8.0.0 fails it three runs in three on darwin (its trailing throttled frame lands after the case's 50 ms wait; with 300 ms it writes `Width: 100`), and the drop-in passes it.

**What `controlroom/ink` became.** Every module of the drop-in was ported again from ink 8's source, decision for decision, on the family's packages. The write protocol (`terminal.ts`): log-update's standard and incremental writers, ink 8's line-update (a changed line from its first changed column), the cursor helpers, the full-clear path (`homeAndEraseDown`, never `CSI 2J`/`3J`), the alternate screen, kitty push and pop, bracketed paste — every sequence from `paratext/csi` and `closeout/cursor`. The ANSI layer (`ansi.ts`): ink 8's ECMA-48 tokenizer and sanitizer (colon SGR rewritten, control characters dropped, SGR deferred past combining marks) and `@alcalzone/ansi-tokenize` 0.3's cell grid (OSC 8 with ST terminators, other OSC dropped). The output grid: intersecting clips, wide characters blanked at a clip edge or under an overlapping write, ignorable code points taking no cell. Text: tabs expanded, CRLF and C1 normalized, truncation per line with cli-truncate 6.1's styled ellipsis (on linegauge's `slice`), `wrap="hard"`. The host config: `<Static>` found in the committed tree, layout listeners, freed subtrees. `App`: raw mode taken and released through `closeout/cursor`'s `rawMode` with ink 8's deferred release, bracketed paste, the paste channel, the kitty query's answer read off the input stream, focus by `useId` and first registration, one shared animation timer. The instance: interactive detection, `suspendTerminal`, `waitUntilRenderFlush`, es-toolkit's throttle reproduced, the Windows console's full clear. New hooks: `usePaste`, `useAnimation`, `useBoxMetrics`, `useWindowSize`. The flexbox port (`flex.ts`) is extended from yoga 3.2.1's source: min and max bounds everywhere yoga applies them, `aspectRatio`, relative and absolute insets, `position: static` and the absolute descendants a containing block lays out through it, `alignContent`'s spacing values with their fallbacks, baseline alignment, and the gap counted in the overflow test. The boundary holds: `terminal.ts` is still the one file that writes, `process.ts` the one that touches the console, `runtime.ts` the one that names the process — the terminal-size fallback reads the streams through it, and the Windows check is `os.platform()`.

**`@inkjs/ui` grades 102 / 102 with one case excluded, because real ink 8 fails it too.** `spinner › spinner` collects every write and expects ink 5's unmount: ink 8 ends a non-interactive debug run with a `\n` (its own suite pins it: `components.tsx` › `debug mode in CI keeps final newline separation after waitUntilExit`) and an empty write that resolves the exit once the queue has flushed. Measured: `@inkjs/ui` 2.0.0's suite against real ink 8.0.0 on React 19.3.0 passes 102 of 103 and fails this case with the same diff. The row's control is still ink 5.2.1 on React 18.3.1, so the drop-in stays graded on both React lines.

**ink 6.8.0 is kept as `ink-6` and not claimed.** Re-vendored byte for byte at `v6.8.0` with the 6.8 row's harness, exclusions and internals; control 584 / 584. The drop-in follows ink 8 where the majors disagree, so 44 of 6's cases assert what 8 changed — the cursor and frame protocol (`cursor.tsx` 7, `render.tsx` 9, `terminal-resize.tsx` 4), the kitty protocol negotiated through the input stream and Delete read as Backspace (`kitty-keyboard.tsx` 10, `hooks-use-input*.tsx` 3), the error overview, focus that `disableFocus` clears, a raw-mode release one microtask later, and `<Static>`'s final render — each ink 8's behaviour, pinned by ink 8's own suite. `SUPPORTED_MAJORS.ink` is `[8]`, so `burgee migrate` now leaves a project on ink 6 under `offMajor`, as it does dotenv 17 and boxen 8.

**What else moved.** `GRADED.ink` is 1304 / 1304 with control 1303, `GRADED.inkjs-ui` 102 / 102, `GRADED_VERSIONS.ink` 8.0.0; `FACADE_EXPORTS['controlroom/ink']` gains ink 8's names. The weight lock's `./ink` budget moves 135,000 → 213,000 B (212,195 measured) against ink 8.0.0's own `build/` of 250,669 B before yoga. The ratchet job's cap moves 20 → 30 minutes: it took 10.5 before, and ink 8's control alone is 268 s serial. The two ink alias examples are versioned 8.0.0, the API the drop-in implements. `kitty.test.ts` pins the new recognizer (`isKittyQueryReply`) in place of the byte-level `kittyReply` it replaces. Five of the target's runs read 1304 and one read 1303 on a single timing case; repeat-and-agree re-grades a row that falls.

**For the owner.**

1. **ink 6 users.** `migrate` stops rewriting ink 6 projects. Claiming 6 again needs the drop-in level with 6's suite, which would mean two behaviours where 6 and 8 disagree. The changeset is `minor` on the reading that a drop-in follows its incumbent's current major (D-20261006-flagstaff-boxen-9 made the same call); under strict semver, a program on ink 6 semantics sees Delete as Backspace, and that makes it a major.
2. **`@inkjs/ui`'s control.** It stays ink 5.2.1 on React 18 so the drop-in keeps a React 18 grade; moving it to ink 8 on React 19.3 would make the spinner case a plain failure of both sides instead of an exclusion.
3. **The benchmarks still compare against ink 6.8.0** (`benchmarks/package.json`). ink 8's build is larger, so the W1–W4 ratios are conservative as they stand; moving the incumbent is a lockfile change of its own.
