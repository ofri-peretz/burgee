**Generated from the build, and locked on every push.** `npm run readme:gates` (`scripts/readme-gates.ts`) bundles `burgee`, `burgee/commander`, `burgee/yargs`, their incumbents and the parity stacks through `bundledRecords` — the bundled half of B4, same fixtures, command and rounding, no `npm pack` — and writes the seven weight gate rows (measured cell *and* verdict) plus every declared quote of those figures in README.md, `vs/commander.mdx`, `vs/yargs.mdx` and the launch kit. `readme-gates-lock.test.ts` runs the same measurement in the root suite (~2 s) and fails naming the command, so a PR that moves a bundled byte regenerates the figures in the same PR. **Exact, not banded**: a band is how 1.514 stayed within tolerance of a number nobody re-read, and the rewrite is one command. The price is that every PR touching those three entries' startup graph touches the README; a conflict there is resolved by re-running the command, not by hand. `benchmarks.mdx` is deliberately not covered — it is a dated snapshot of a chosen, published run (`published.ts`) and republishing it is a person's decision
