**Ten intents are opened at `review`, each with a `spec.md`, ranked on wave 3's demand × fit ÷
cost scale so the two waves compare.** The table, the scores, the lanes and the order are in
[`next-wave-4-2026-10.md`](../research/next-wave-4-2026-10.md). They stay at `review`, not
`approved`: this run was asked for Stages 1 and 2 only, so the Design → Build gate is the next
human or delegated step, not this file.

**Value gained.** Every selected intent either closes an open gap with a measured number
(closeout's two B4 rows, `schema-bytes` with no gate, `fix:` lines quoted for POSIX only,
`ArgumentSpec` with no `choices`), moves a published claim (burgee's tarball, the locale-pack eval
median), adds a capability the incumbents' trackers ask for (a default command, typed
positionals), grades a host with more than 100 M weekly downloads (three colour façades,
158,336,748 /wk together in `replacement-map.md`), or takes CI time back from a queue that
cancelled 24 of its last 30 Compatibility runs.

**Three calls made here rather than left open.**

- **`commander-front-end-diet`'s residual is not reopened.** `burgee/commander` at about 1.415×
  commander is that intent's R4 ratchet, and D-20261012-commander-front-end-floor already decided
  what stays static and why. A wave-4 intent for the same bytes would re-do an existing intent,
  which wave 3's rule says does not count.
- **The MCP `2026-07-28` stateless revision waits.** Gap B-20261012-mcp-2026-07-28-stateless
  itself records that a dual-era client probes `server/discover`, gets `method not found`, and
  falls back to `initialize`. No client that speaks only `2026-07-28` is measured here. Revisit
  when the `b1-mcp-arm` readings (first on Tuesday) or a client release show one.
- **The compat-oracle lane takes one wave-4 host group, the colour façades**, because it scores
  above `caique/prompts` (8.3 against 6.7) and the lane is serial behind wave 2 and wave 3 work.

**Reversal.** Move any rejected row into a new intent with its own decision. Nothing in the tree
changes with this file except the plans it records.
