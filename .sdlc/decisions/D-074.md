**Owner**, because it changes a published instrument. The axis says it measures "what a user's application grows by", and it bundles with esbuild `--outfile`, which **inlines** `await import()` — so `completions.js` (7,763 B) is counted as startup weight when every real bundler with code splitting emits it as a chunk that is not loaded at startup. The measurement is over-counting against its own stated purpose. Default: **leave the instrument alone.** Changing a measurement while it is failing is the one move this repository has the most scar tissue about, whatever the merits, and the merits here are real enough to deserve a decision rather than a patch
