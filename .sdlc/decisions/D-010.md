**Table stakes, not the moat, and never what byte budgets are cut to fit.** A CLI costs an agent nothing until called; an MCP server's tool definitions are loaded before any work happens and cost tokens every turn whether used or not. The moat is a CLI legible without a server — `--schema`, `--json`, exit codes, and `fix:` naming a command rather than describing a problem. See §6
