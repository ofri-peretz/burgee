**Owner — it needs a credential only you can issue, and here is the bill.** B1 spawns `claude -p` for 5 tasks × 2 builds × 5 runs = **50 agent runs** at 12–15 turns each, and it refuses to run without `CLAUDE_CODE_OAUTH_TOKEN` or `ANTHROPIC_API_KEY`. On `ANTHROPIC_API_KEY` the estimate is **$5–15 for a complete pass** (Sonnet, ~60 K input and ~3 K output per run, cache-dependent); on `CLAUDE_CODE_OAUTH_TOKEN` there is no marginal charge and it draws on the subscription instead. Separately, `DEFAULT_MODEL` is pinned to `claude-sonnet-4-5`, which is two generations behind — the pin is deliberate (a model change starts a new band history) but it should be re-pinned before the first real run rather than after, since the first run is what the band history starts from. Default while unanswered: **the axis keeps skipping loudly and the README keeps saying `unmeasured`**, which `emit.test.ts` enforces — nothing in the suite can turn a run that did not happen into a number
