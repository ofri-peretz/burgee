**Private packages get versions and changelogs; `privatePackages.version` is now `true`.** `.changeset/` is a queue whose contract is that a release empties it, and `compat-oracle` is private, so with versioning off its changesets were never consumed — nine had accumulated. Because `changesets/action` opens a Version PR whenever the directory is non-empty, every push to `main` raised a PR whose `changeset version` produced **no file changes at all**: #399 and #408 were both empty `chore(release): version packages` commits, closed by hand, each sitting at 0 checks against 3 required ones. The shape was self-inflicted — `Changeset present` requires a changeset for any change under `packages/`, which obliged authors to write files the configuration guaranteed could not be consumed. The alternative was to exempt private packages from the check and delete the nine; **versioning them is the better answer because `compat-oracle` is the instrument every published compat number comes from**, and on 2026-09-21 alone its behaviour changed three times in ways that moved those numbers. A changelog for the instrument is worth more than a clean `.changeset/`.
