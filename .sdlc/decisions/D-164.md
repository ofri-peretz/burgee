**Hold the loop: the deadline's timer is `ref`'d on every `run()` except `'beforeExit'`'s.** Measured first: the same shape exits 0 on three paths, not one — SIGTERM through `install()`, an uncaught throw through `install()` (exit 0 *and* the error never printed), and SIGTERM through `closeout/exit-hook`, where `exit-hook@5.1.0` itself exits 143 on the same program because its force-exit timer is not `unref`'d. A held clock fixes all three with one line in `registry.ts`: the deadline fires, the breach report names the handler, and the caller's own leave runs — re-raise, exit 1, exit 143. **Rejected: re-raising from the `'exit'` listener.** It is a second leave path in `install.ts` only, so the throw and the façade stay at 0; it leaves before the deadline, so the breach report — R3's product — is never printed on exactly the path where a handler hung; and it adds state to `install()` for what the bound already does. `'beforeExit'` keeps an `unref`'d clock: that process was leaving on its own, and holding it there was measured to break R4 — a pending SIGTERM becomes a second trigger whose `run()` resolves at once, so `install()` raises before `restore` is invoked, and `terminal-restore.test.ts` fails. **Weight:** burgee bundled 24,262 → 24,277 B, under the 24,282 ceiling, which is not raised — the 27 B `hold` costs are paid 12 B by deleting a dead `undefined` guard in `Deadline.cancel`. **Found while measuring:** `terminal-restore.test.ts`'s 'a hang that holds nothing' case never ran the signal path. Nothing holds its loop after the timer that sends SIGTERM and Node's signal watcher is `unref`'d, so `'beforeExit'` starts the shutdown and the SIGTERM is never delivered to a listener. Its comment now says so; the signal-started shape is in `signal.test.ts`. A process that receives a signal in the last callback before its loop drains still exits 0 — Node's behaviour with any listener installed, recorded in `closeout/spec.md` and not fixed here. Proven: three spawned cases in `signal.test.ts` fail on the unfixed build (status 0 for each) and pass on the fix; `exit-hook` 21 / 21, `restore-cursor` 6 / 6, `signal-exit` unchanged (126 / 135 on darwin, identical before and after)
