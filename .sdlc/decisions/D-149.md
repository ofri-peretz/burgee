**Both exist, both run offline, neither is on npm; a pinned `floor` axis in its own suite, measured on CI and published from that run.** clispec.dev is a spec ([rvben/clispec](https://github.com/rvben/clispec), v0.3 candidate, CC BY 4.0) with a scorer, [rvben/clispec-cli](https://github.com/rvben/clispec-cli) v0.3.0 (MIT, Rust); cli-agent-lint is [Camil-H/cli-agent-lint](https://github.com/Camil-H/cli-agent-lint) v0.3.5 (MIT, Go), and its `checks/registration.go` registers exactly 34 checks. Neither links an HTTP client. The npm package named `clispec` (0.2.6) is an **unrelated** project by another author, so "a devDependency pinned exactly" was impossible and would have been wrong: the pin is `benchmarks/floor-tools.ts` — one version per tool and the SHA-256 of each platform's release archive, copied from the assets' own digests, with a mismatch refused. **Own suite (`external-floor`)**, not a fifth cheap axis: a document is publishable only when complete, so folding the floor into `cli-benchmarks` would have made publishing its first number republish every machine-dependent millisecond; and its numbers move when the checkers release, not when we change. **Executed on the CI runner only** — a third-party binary is not run on a laptop to produce this — and the first run (36064855115, `ddb3eaf`, four-core EPYC) is promoted to `2026-09-24.json` exactly as #129 promoted a CI run for `cli-benchmarks`. Verdicts are recorded as the tools print them and never re-scored, including clispec probing a `schema` subcommand where burgee answers `--schema` — that is B22, not a parser exemption. Burgee's two scores are gated as a ratchet at their landing values (6 and 78); the incumbents are graded and never gated. No control band yet: two deterministic numbers with a gate need no σ
