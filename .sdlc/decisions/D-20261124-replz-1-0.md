**Yes, replz meets every written 1.0 criterion.** This record, with the major changeset beside
it, cuts replz 1.0.0. It follows
[`D-20261124-verification-family-1-0`](./D-20261124-verification-family-1-0.md), which cut
truefit, truepass, provedone and contractdiff and left replz for its own record once it had been
released and dogfooded: replz 0.3.0 is on npm, and burgee runs it on itself (`.sdlc/replz/`, 20
cases, held by `scripts/replz-lock.test.ts` on every push).

Measured on linux (4 cores) with Node 24.13.0, at main `5e6a544f4f`.

## Criterion 1: the spec is fully built

`.sdlc/intents/replz/spec.md` now carries a Status table: R1 to R4 and R6 built, each with the
test that holds it. R5 as written (`replz mine`, clustering review comments into rule candidates)
was half built: drafting cases from reverts and fixes shipped as `replz propose`. The other half
moved to its own intent, [`replz-mine`](../intents/replz-mine/intent.md). It is a new command, so
under semver a minor of 1.x, and it changes nothing an existing command does. **Not built: 0.**

## Criterion 2: every claimed drop-in is level with its incumbent

replz claims no drop-in. Its README says it covers the review half of promptfoo and gives a
migration path, not promptfoo's API.

## Criterion 3: the coverage gate

`npx vitest run --coverage.enabled` in `packages/replz`, 2026-11-24: 83 tests; statements
228 / 228, branches 89 / 89, functions 65 / 65, lines 177 / 177.

## Beyond the bar: mutation

`scripts/mutation.ts full`, oxmutate 2.18.4, three mutants at a time: 570 killed, 1 timeout, 0
survived, 0 without coverage, **100%** in 1.38 minutes. It is replz's first floor in
`.sdlc/bands/mutation-ratchets.json`.

## What 1.0 promises

The `.` entry (`parseLog`, `propose`, `parseCase`, `selectCases`, `parseConfig`, `replayCase`,
`score`, `program` and the exported constants), the `replz` bin with `check`, `run` and
`propose`, their options, the `--json` report shape, the case-file and config formats under
`.sdlc/replz/`, the `history.jsonl` line, and the exit codes.

## Out of scope

- replz's intent success criteria (a first committed report on burgee's reviewer, a second run
  after a REVIEW.md change, 20 cases per repo) are about using it, not about its API; they stay
  open on the intent.
